# موقع تفاصيل الرئيسي

17 نوفمبر 2026. النطاق الرئيسي لهذه التجربة tafaseel-learn.com. يبقى النطاق القديم قائمًا دون تعديل.

## المراجع والملاحظات

- [أعناب](https://aanaab.com/): فصل احتياجات الأفراد والجهات، اكتشاف الدورات، خدمات مكملة، انتقال للحساب. لا ننقل ادعاءاتها أو شركاءها أو صورها.
- [دروب](https://doroob.sa/ar/): بوابة عامة، مسارات وخدمات، مساعدة وسياسات، تحقق من الشهادات. شارة الحكومة وبيانات الاعتماد خاصة بدروب ولا تخص تفاصيل.
- [إدراك](https://www.edraak.org/) و[الدخول](https://programs.edraak.org/login/): بحث وتصنيف ومحتوى تعليمي، ثم دخول واضح وإنشاء حساب. لا نوفر دخول Google أو Facebook دون إعداد حقيقي.

## القرار البصري

ألوان: الأزرق #254f97، الحبر #162f4f، الخلفية الدافئة #f7f5ef، السطح #ffffff، الأخضر الفاتح #dce8ae، الرمادي #66748a. خط IBM Plex Sans Arabic المحلي بأوزان 400–700، مع عناوين كبيرة دون تباعد مصطنع للحروف العربية. صور القاعات الأصلية من ملفات المركز، مع توضيح أن الصور تصف المكان.

واجهة عربية RTL: رأس تنقل واضح → افتتاحية غير متماثلة مع صورة قاعة أصلية وبحث → مجالات التعلم → دورات مختارة → رحلة المتدرب → خدمات الأفراد والجهات → المركز والمكتبة → مساعدة وتواصل → تذييل كامل. للمحمول قائمة قابلة للفتح وتخطيط عمودي، دون تمرير أفقي. العودة من المنصة تذهب للموقع الجديد.

المراجعة: لا إحصاءات نجاح أو تقييمات أو شركاء أو اعتمادات مختلقة. أعداد الدورات والمجالات من الدليل الفعلي. لا نعرض مسودات التعلم أو محتواها الخاص. صفحات الدورات تعرّف بالبرنامج وتبيّن حالة الدفعة؛ يُفتح التسجيل عندما تنشر الإدارة الدورة وتفتح الالتحاق. تُحفظ طلبات التواصل مشفرة ولا تدعي إرسال بريد أو SMS. تمارين المكتبة توضيحية غير رسمية وغير مُقيّمة.

## التشغيل

الصفحات العامة: الرئيسية، الدورات وتفاصيلها، المجالات، عن المركز، صور المركز، تدريب الجهات، الانضمام كمدرب، المكتبة والمقالات والتمارين، المساعدة، التواصل، التحقق من الشهادات، الخصوصية، الشروط، سياسة التسجيل، خريطة الموقع، تسجيل الطالب. المنصة: /dashboard وما يتبعها. إدارة الموقع والطلبات: /website للإدارة فقط. البيانات النصية قابلة للتعديل من اللوحة، والرسوم والدفعات من إدارة الدورات الحالية.

بناء Vite/PHP الحالي مستمر. CSS معزول للموقع، ترميز نصي آمن دون HTML محرر، حماية CSRF والصلاحيات وتحديد المعدل. نسخة HTML عامة ذات بيانات وصفية لكل مسار، وrobots/sitemap يستثنيان الصفحات الخاصة. وجودها لا يثبت الفهرسة. إدارة المصادقة الإضافية معطلة على الإنتاج بطلب المالك؛ دخول الإدارة بكلمة المرور المحددة، ولا ندعي وجود تحقق SMS.
