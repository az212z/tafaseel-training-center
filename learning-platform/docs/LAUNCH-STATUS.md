# حالة تجهيز tafaseel-learn.com — 2026-11-17

## ما تم التحقق منه

- الموقع الجديد مسجل في Hostinger على باقة Business، منفصل في hPanel عن موقع المركز الحالي. الدومين نشط.
- الموارد مشتركة ضمن حساب الاستضافة: 50 GB، و600 ألف inode، وحتى 50 موقعًا. لا توجد نتائج اختبار تحمل لهذه الاستضافة.
- origin في مثال إعداد الإنتاج هو `https://tafaseel-learn.com`، مع production وdemo=false وفرض المصادقة الثنائية للعاملين.
- حزمة النشر تبني الواجهة وتضم خادم PHP وSDK خارج public_html؛ لا تضم إعدادًا فعليًا أو قاعدة أو كلمات مرور أو حسابات توضيحية.
- اختبار حزمة مستقلة: ترحيل قاعدة نظيفة، اتصال مدخل PHP، تحميل AWS SDK، وصفر حسابات توضيحية.
- آخر فحص SQLite: 57 حالة أساسية و59 حالة تكامل. مزودو الدفع والرسائل والفيديو وزوم محاكاة محلية وقت الاختبار.
- فحص npm وComposer بلا تنبيهات معلنة وقت التجهيز. نتائج ماسح الأسرار عالية الشدة الأربعة تخص قيم اختبار مصطنعة ضمن tests وليست حسابات إنتاج.
- بصمتا صفحة الموقع الحالي وواجهة /admin/ مطابقتان قبل/بعد إضافة الموقع الجديد، HTTP 200.

## ما لا يزال معلقًا

1. وصول نشر مؤقت مصرح به إلى الاستضافة. مفتاح SSH للحساب المشترك يمنح صلاحيات أوسع من مجلد المنصة؛ يقتصر العمل على الموقع الجديد ويُسحب المفتاح بعد التسليم. لا تُدرج المفاتيح أو known_hosts أو بيانات الاتصال الخاصة في المستودع.
2. إنشاء MariaDB ومستخدم خاص بها، وإعداد مشفر خارج جذر الويب بصلاحيات مقيدة، وترحيل المخطط دون بيانات تجربة.
3. إنشاء حساب إدارة وتسليمه بشكل خاص، وتفعيل صاحبه للمصادقة الثنائية.
4. التحقق من DNS وHTTPS وفرض النطاق الأساسي والترويسات وعدم إتاحة ملفات الخادم والإعداد والتخزين للويب.
5. مهمة worker وسجلها، ونسخة ملفات/قاعدة/مفتاح منفصلة، وتجربة استعادة إلى وجهة خاصة.
6. اختبار الطالب والمدرب والإدارة وولي الأمر على HTTPS، مع ملف وواجب واختبار وحضور وشهادة بحسابات اختبار معزولة ثم إزالتها.
7. حسابات المركز الفعلية لدى ميسر وتقنيات وزوم وBunny/S3. لا يُدّعى تفعيلها أو نجاح دفع/SMS/فيديو سحابي قبل تحقق حي بحسابات المركز.

## فحص ما قبل النشر

| المجال | النتيجة الحالية |
|---|---|
| الحماية | صلاحيات وCSRF وOrigin وMFA وتشفير وقيود الملفات واختبارات منع التصعيد موجودة؛ TLS وترويسات الإنتاج وصلاحيات الملفات معلقة |
| القاعدة | مخطط وترحيلات واستعلامات محضرة واختبارات SQLite/MariaDB سابقة؛ قاعدة الإنتاج ونسخها معلقة |
| جودة الكود | TypeScript وصياغة PHP وبناء الإنتاج ناجحة، شاشة تعافٍ للأخطاء موجودة |
| الاعتماديات | lockfiles مضمنة، إصدارات أدوات البناء مثبتة، audit بلا تنبيهات معلنة |
| الذكاء الاصطناعي | غير مطبق؛ لا توجد خدمة AI داخل المنصة |
| النشر | الحزمة جاهزة ومجربة مع قاعدة فارغة؛ التثبيت الحي غير مكتمل |
| الواجهة | عربية RTL، ملفات الخط محلية، فحوص حاسوب وجوال سابقة؛ الدومين الفعلي معلق |
| المراقبة | سجل عمليات ومعرف طلب وأخطاء خادم دون أجسام أو أسرار؛ تنبيه خارجي واختبار استعادة الإنتاج معلقان |

لا تُعد هذه الحالة موافقة تشغيل عام. لا ضمان بعدم وجود أخطاء أو عدم الاختراق. الصفحات ذات البيانات الحساسة لا تعتمد على إخفاء الواجهة؛ الصلاحيات تطبق في الخادم. البيانات الإجمالية الأولية في لوحة التحكم لا تزال محدودة وليست واجهة مناسبة لأحجام غير محدودة؛ دليل السعة يوضح الحدود.

## التراجع

احتفظ بالحزمة السابقة خارج public_html قبل أي تحديث للمنصة الجديدة. عند فشل فحص الصحة أعد ملفات الإصدار السابق فقط، ولا تحذف القاعدة أو تغيّر مفتاح التشفير. ترحيلات الإصدار الحالي إضافية وقابلة للتكرار؛ اختبر التراجع مع نسخة قاعدة منفصلة عند إضافة ترحيل مستقبلي يغير البيانات. لا تعدل ملفات tafaseel-training.com أو قاعدته لعلاج مشكلة المنصة.
