# نسخة العرض على GitHub Pages

الرابط: [نسخة العرض](https://az212z.github.io/tafaseel-learning-preview/)

نسخة عامة لاختبار التصميم ومسارات العمل قبل النشر الفعلي على Hostinger. استخدم أزرار الإدارة والمدرّب والطالب وولي الأمر؛ لا تحتاج إلى كلمة مرور. كل الأسماء والحسابات ونتائج التدريب مصطنعة.

- إضافة وتعديل الدورات، التسجيل، الدروس النصية وروابط الفيديو وملفات الموارد.
- الواجبات والتسليم والتقييم، محاكاة الاختبارات والتصحيح، الجدولة والحضور والشهادات والتقارير والإعلانات والدعم.
- تُحفظ التعديلات والملفات في IndexedDB في متصفح المستخدم فقط، ولا تُرسل إلى قاعدة مشتركة. تبقى بعد تحديث الصفحة؛ لا تنتقل إلى جهاز آخر. حذف بيانات الموقع أو تغيير المتصفح يفقد الإضافات.
- «إعادة بيانات العرض» تعيد البيانات الأصلية وتحذف إضافات وملفات العرض من هذا المتصفح فقط.
- الحد 10MB لكل ملف، و30MB لمجموع ملفات العرض.
- إدخال الهوية ورفع مرفقاتها معطّلان. لا تدخل أسماء أو جوالات أو ملفات طلاب حقيقية. التخزين المحلي غير مشفر.
- الحسابات والصلاحيات والتوقيت والتصحيح محاكاة في المتصفح. GitHub Pages لا يشغّل PHP أو قاعدة بيانات؛ لا تعتمد عليه للاختبارات الفعلية أو حماية البيانات. لا توجد كلمات مرور أو مفاتيح أو ملفات قاعدة بيانات في مستودع العرض.
- `HashRouter` يتيح تحديث الصفحات الداخلية على مسار GitHub Pages. كل الصور والخطوط محلية ضمن مسار المشروع.

## إعادة البناء

```sh
npm ci
npm run test:preview
npm run build:preview
```

`dist-preview/` فقط هو ناتج النشر العام. تحذف أداة التحضير `api/` وملفات ضبط الاستضافة، وتتحقق من عدم وجود PHP أو قواعد بيانات أو ZIP. لا تنشر مجلد المصدر كاملًا كدليل موقع ثابت. يحتوي ناتج البناء `build-manifest.json` على SHA256 لكل ملف للتحقق من النسخة المنشورة.

النسخة التي تعمل بالخادم ما زالت منفصلة، وتُبنى بالأمر `npm run package`. النشر النهائي يتطلب ربط استضافة المركز واختبار إعداداتها وقاعدة بياناتها قبل إدخال البيانات الحقيقية.

## إضافات 2.0

طلب تسجيل طالب وهمي ومراجعته من الإدارة، كتالوج برسوم وتسجيل، محاكاة دفع محلية واضحة، حقائب تعليمية بمرفقات، موافقة رسائل ولي الأمر وسجل غياب توضيحي، وصفحة حالة الخدمات. زوم وتخزين S3 والفيديو السحابي وإرسال SMS غير مفعلة في العرض العام؛ تستخدم النسخة الأساسية الخادم ومفاتيح المركز عند التفعيل. محاكاة الدفع لا تفتح بوابة دفع ولا تخصم أموالًا.
