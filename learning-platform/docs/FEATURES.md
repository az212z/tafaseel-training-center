# ما يتضمنه الإصدار

| القسم | الوظائف المنفذة |
|---|---|
| الهوية والواجهة | العربية RTL، هوية المركز الأصلية، خط محلي، جوال وحاسوب، بحث عام، حالات فارغة ورسائل تحقق |
| الحسابات | دخول فعلي، مدير ومدرب وطالب وولي أمر، إنشاء الحسابات وإيقافها، تعيين كلمة مرور للطلاب، تغيير كلمة المرور، TOTP إلزامية افتراضيًا للمدربين والإدارة في الإنتاج، طلبات تسجيل عامة تحتاج مراجعة |
| الطلاب | ملف شخصي، ميلاد ومدينة، هوية اختيارية مشفرة، جوال الطالب، اسم وجوال ولي أمر منفصلان، ربط حساب ولي الأمر، موافقة الحفظ |
| الدورات | إضافة وتعديل دورة، تحديد مدرب ومسار وسعة، مسودة ونشر وأرشفة، تسجيل الطلاب مع منع التكرار وتجاوز المقاعد |
| المحتوى | دروس نصية، MP4 محمي، YouTube/Vimeo، PDF وصور، ترتيب ومدة، تأكيد إكمال الدرس ونسب تقدم فعلية |
| الواجبات | تعليمات وموعد ودرجة، إجابة نصية ومرفق، تعديل قبل التقييم والموعد، تصحيح وملاحظات، قفل التسليم المقيم |
| الاختبارات | محرر أسئلة وخيارات وإجابة صحيحة، مدة ونسبة اجتياز ومحاولات، توقيت وتصحيح خادم، نتائج وتصدير |
| الجدول | جدولة بداية ونهاية وقاعة ورابط لقاء، عرض القادم والسابق بتوقيت الرياض |
| الحضور | حاضر وغائب ومتأخر وبعذر، رصد جماعي، سبب إلزامي للتعديل، صلاحيات مدرب الدورة، تصدير |
| الملفات | موارد الدورة، مرفقات الواجب، ملفات هوية خاصة، تحكم بالتنزيل، تشفير وتحقق MIME وحجم |
| الشهادات | تحقق متطلبات الإتمام، رقم عشوائي فريد، اسم الطالب والدورة والساعات، طباعة أو حفظ PDF من المتصفح |
| المتابعة | تقارير تقدم وحضور، تصدير CSV آمن من الصيغ، إعلانات عامة أو للدورة داخل المنصة، صندوق طلبات دعم وردود |
| الحقائب | إنشاء حقيبة لكل مادة بإصدار ووصف، إضافة موارد خاصة بالدورة وترتيبها، وصول المسجلين فقط |
| الدفع | أسعار نهائية بالريال، تسجيل مجاني أو فاتورة ميسر مستضافة، التحقق الخادمي من المبلغ والعملة، منع تكرار الطلب والتسجيل، مراجعة الطلبات غير المؤكدة |
| رسائل الغياب | موافقة ولي الأمر، طابور مشفر، مهلة تصحيح الغياب، إلغاء عند تغيير الحالة أو الموافقة، سجل إرسال مقنّع، عامل CLI |
| زوم | إنشاء اجتماع بخادم المركز، فصل رابط الانضمام عن رابط المضيف، صلاحيات التسجيل والتوقيت، أحداث موقعة وسجل اتصالات للمراجعة |
| الفيديو الكبير | رفع TUS قابل للاستئناف إلى Bunny Stream، معالجة وحالة جاهزية، ربط الفيديو بالدرس، تشغيل برابط موقع قصير الصلاحية |
| التخزين السحابي | تخزين S3 خاص عبر AWS SDK، تشفير المرفقات قبل الرفع، حصص مساحة وحجز متزامن، تنزيل بعد الصلاحية |
| الإدارة | إعدادات المركز ونسبة حضور الشهادة، سجل عمليات، دليل نشر ونسخ واستعادة، حزمة Hostinger منفصلة |

المحتوى التدريبي النهائي، والمدربون الحقيقيون، والطلاب والمواعيد والأسعار والاعتمادات تحتاج إدخال المركز. بيانات المعاينة أسماء وحسابات مصطنعة من نطاق example.test. لا يُرفع ملف التجربة أو الحسابات في الأرشيف.

التكاملات الخارجية تحتاج حسابات المركز ومفاتيح خاصة واختبارًا حيًا. نسخة GitHub عرض محلي في المتصفح، ومحاكاة الدفع فيها لا تنفذ عملية مالية. حالة SMS «مقبولة لدى المزود» لا تعني تسليمها إلى الهاتف. الحضور يرصد يدويًا؛ اتصال زوم مؤشر مراجعة ولا يثبت هوية الطالب.

لا يتضمن الإصدار: مراقبة اختبارات بالكاميرا، SCORM/xAPI، تطبيق جوال أصلي، بصمة/QR، بريدًا آليًا، فحص فيروسات للمرفقات، فوترة ضريبية محاسبية، استرداد مبالغ تلقائيًا، أو مزامنة حية مع النظام السابق. الشهادات مستندات إتمام للمركز ولا تعني اعتماد جهة خارجية.
