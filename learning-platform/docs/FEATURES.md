# ما يتضمنه الإصدار

| القسم | الوظائف المنفذة |
|---|---|
| الهوية والواجهة | العربية RTL، هوية المركز الأصلية، خط محلي، جوال وحاسوب، بحث عام، حالات فارغة ورسائل تحقق |
| الحسابات | دخول فعلي، مدير ومدرب وطالب وولي أمر، إنشاء الحسابات وإيقافها، تعيين كلمة مرور للطلاب، تغيير كلمة المرور، TOTP للمدربين والإدارة |
| الطلاب | ملف شخصي، ميلاد ومدينة، هوية اختيارية مشفرة، جوال الطالب، اسم وجوال ولي أمر منفصلان، ربط حساب ولي الأمر، موافقة الحفظ |
| الدورات | إضافة وتعديل دورة، تحديد مدرب ومسار وسعة، مسودة ونشر وأرشفة، تسجيل الطلاب مع منع التكرار وتجاوز المقاعد |
| المحتوى | دروس نصية، MP4 محمي، YouTube/Vimeo، PDF وصور، ترتيب ومدة، تأكيد إكمال الدرس ونسب تقدم فعلية |
| الواجبات | تعليمات وموعد ودرجة، إجابة نصية ومرفق، تعديل قبل التقييم والموعد، تصحيح وملاحظات، قفل التسليم المقيم |
| الاختبارات | محرر أسئلة وخيارات وإجابة صحيحة، مدة ونسبة اجتياز ومحاولات، توقيت وتصحيح خادم، نتائج وتصدير |
| الجدول | جدولة بداية ونهاية وقاعة ورابط لقاء، عرض القادم والسابق بتوقيت الرياض |
| الحضور | حاضر وغائب ومتأخر وبعذر، رصد جماعي، سبب إلزامي للتعديل، صلاحيات مدرب الدورة، تصدير |
| الملفات | موارد الدورة، مرفقات الواجب، ملفات هوية خاصة، تحكم بالتنزيل، تشفير وتحقق MIME وحجم |
| الشهادات | تحقق متطلبات الإتمام، رقم عشوائي فريد، اسم الطالب والدورة والساعات، طباعة أو حفظ PDF من المتصفح |
| المتابعة | تقارير تقدم وحضور، تصدير CSV آمن من الصيغ، إعلانات عامة أو للدورة داخل المنصة، صندوق طلبات دعم وردود |
| الإدارة | إعدادات المركز ونسبة حضور الشهادة، سجل عمليات، دليل نشر ونسخ واستعادة، حزمة Hostinger منفصلة |

المحتوى التدريبي النهائي، والمدربون الحقيقيون، والطلاب والمواعيد والأسعار والاعتمادات تحتاج إدخال المركز. بيانات المعاينة أسماء وحسابات مصطنعة من نطاق example.test. لا يُرفع ملف التجربة أو الحسابات في الأرشيف.

لا يوجد في الإصدار: دفع إلكتروني، إرسال SMS أو بريد تلقائي، بث لقاءات مستضاف، SCORM/xAPI، مراقبة اختبارات بالكاميرا، تطبيق جوال أصلي، تسجيل حضور بالبصمة/QR، مزامنة حية مع النظام السابق، فحص فيروسات للمرفقات، شهادة اعتماد من جهة خارجية. هذه تكاملات ومشروعات لاحقة وليست أزرارًا معطلة تُعرض كوظائف عاملة.
