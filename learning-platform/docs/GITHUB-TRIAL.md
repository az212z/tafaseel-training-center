# تجربة كاملة مؤقتة داخل GitHub Codespaces

[افتح إعداد المنصة الكامل](https://codespaces.new/az212z/tafaseel-training-center/tree/feat/learning-platform?devcontainer_path=.devcontainer%2Flearning-platform%2Fdevcontainer.json).

هذه نسخة الخادم وقاعدة البيانات نفسها، تعمل مؤقتًا داخل Codespace خاص بحساب GitHub. تختلف عن نسخة Pages التي تحفظ التغييرات في المتصفح. الحفظ هنا في SQLite ومرفقات خاصة داخل مساحة العمل، ويمكن تجربة الحسابات والتسجيل والدورات والدروس والواجبات والتصحيح والاختبارات والحضور والشهادات والحقائب فعليًا. بيانات البداية مصطنعة، ولا توجد بيانات طلاب المركز أو كلمات مرور ثابتة في Git.

## الفتح أول مرة

1. سجل دخولك إلى حساب GitHub، وافتح الرابط. اختر إعداد «تفاصيل — تجربة كاملة بخادم وقاعدة بيانات» وجهاز نواتين، وراجع الرصيد المجاني وحد التكلفة في حسابك قبل الإنشاء. لا يتطلب الإعداد هوستنغر أو خدمات مدفوعة، لكن Codespaces قد يحتسب استهلاكًا بعد تجاوز حصة حسابك؛ لا توجد ميزانية أو وسيلة دفع يضبطها هذا المشروع.
2. انتظر تثبيت البيئة وبناء المنصة. تفتح المنصة من المنفذ **8080** بعد بدء التشغيل. أبق المنفذ **Private** كما هو افتراضيًا. لا تحول الوصول إلى Public؛ هذه بيئة اختبار شخصية وليست نشرًا عامًا.
3. تعرض طرفية GitHub الخاصة بيانات دخول لأربعة أدوار. لكل حساب كلمة عشوائية مختلفة، ولا تحفظ في المستودع. إن لم تظهر، نفذ داخل طرفية مساحة المنصة `npm run trial:accounts`. لا ترسل كلمات المرور أو صورة الطرفية في المحادثة.
4. ادخل بالبريد وكلمة المرور. حساب الإدارة والمدربين يطلب تفعيل المصادقة الثنائية من إعدادات الأمان قبل استخدام الأدوات. أكملها بنفسك بتطبيق المصادقة؛ تبقى هذه الحماية مفعلة في التجربة.
5. جرّب الحسابات الأربعة، وأنشئ طالبًا أو دورة أو واجبًا ثم أعد فتحها للتحقق من حفظ البيانات. الحفظ مرتبط بالـCodespace نفسه، وليس بجهاز المتصفح.

الصفحة عند عدم تشغيل Codespace أو عند توقفه ليست دليلًا على تعطل المنصة؛ افتح بيئة GitHub واستأنفها ثم منفذ 8080. عنوان التطبيق الفعلي ينشئه GitHub باسم البيئة، بالشكل الموثق `https://CODESPACE-NAME-8080.app.github.dev`. لا يوجد رابط خادم فعلي قبل إنشاء بيئتك.

## الاستئناف والبيانات

التثبيت الأول فقط ينشئ بيانات الاختبار. الاستئناف لا يعيد تعبئتها ولا يبدل كلمات المرور أو مفتاح التشفير. تحفظ الملفات في `learning-platform/.local/github-trial/` مع صلاحيات خاصة، خارج الجذر العام وGit. لا تشارك هذا المجلد. لا تستبدل ملف الإعداد المحلي المعتاد أو قاعدة تجربة أخرى.

Codespaces بيئة مؤقتة: قد تتوقف عند الخمول وتحذف بعد مدة الاستبقاء، وتحتسب مساحة التخزين حتى وهي متوقفة بحسب سياسة حسابك. أنشئ نسخة احتياطية قبل حذفها أو نقلها، ولا تستخدمها كسجل رسمي لطلاب حقيقيين. إيقافها عند انتهاء الاختبار يوفر وقت التشغيل؛ احتفظ بالبيئة نفسها لاستئناف بياناتك.

لا تضف ملفات الهوية أو أرقام طلاب حقيقية أثناء هذه المرحلة. قبل النقل النهائي يلزم قرار بشأن نقل بيانات الاختبار أو بدء قاعدة نظيفة؛ لا يجرى النقل تلقائيًا. النشر إلى Hostinger لا يبدأ إلا بطلب المستخدم لاحقًا.

## الخدمات الخارجية

ميسر وSMS وزوم وBunny وS3 تبقى غير مفعلة حتى إعداد حسابات المركز الخاصة. المنصة تتعامل مع عدم الإعداد برسالة واضحة ولا تدعي إرسالًا أو دفعًا حقيقيًا. لا توجد محاكاة دفع متصفح في تشغيل الخادم. الربط الحي يحتاج مفاتيح واختبار مزود فعلي وفق [دليل التكاملات](INTEGRATIONS.md).

المجلد الخاص يحتفظ بإعداد الخدمات عند الاستئناف. عامل رسائل الغياب يحتاج تشغيل `php server/console.php worker` مع متغير `TAFASEEL_CONFIG` الذي يشير إلى إعداد التجربة؛ لا يبدأ إرسال رسائل من تلقاء نفسه. صفحة الخدمات تعرض عدم وجود عامل حتى إعداده. لا تضع مفاتيح في devcontainer أو المستودع.

## حدود التشغيل

PHP built-in server وSQLite هنا مخصصان للاختبار الخاص، لا لتشغيل عام أو اختبار أحمال. لا تغيّر الرؤية إلى Public لتجاوز تسجيل GitHub. الخدمات الخارجية والوصول لعدة مستخدمين مستقلين واختبار الأحمال والنسخ الإنتاجي تقيم لاحقًا عند النشر. Codespaces لا يمثل إطلاقًا على Hostinger.
