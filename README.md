# مركز تفاصيل للتدريب

موقع عربي باتجاه RTL، مبني بـ Next.js وReact وTypeScript. الواجهة جاهزة لعرض الدورات والحجز عبر واتساب، دون قاعدة بيانات أو نظام دفع أو حسابات متدربين.

[الموقع](https://az212z.github.io/tafaseel-training-center/) · [المستودع](https://github.com/az212z/tafaseel-training-center)

## التشغيل

يتطلب Node.js 22 أو أحدث وnpm.

```sh
npm ci
npm run dev -- --port 3013
```

المعاينة أثناء التطوير: http://localhost:3013

لتجربة نسخة الإنتاج:

```sh
npm run build
npm start
```

رابط نسخة الإنتاج: http://localhost:3014
يمكن تغيير المنفذ بمتغير `PORT` والمضيف بمتغير `HOST`.

## الصفحات

- الرئيسية، دليل الدورات مع البحث والتصفية، وصفحة مستقلة لكل واحدة من الدورات الـ13.
- أربعة مسارات مستقلة: الاختبارات، الإنجليزية، التطوير الذاتي والمهني، الفنون والتصميم.
- عن المركز، التواصل، طلب الحجز، الأسئلة الشائعة، الخصوصية، وآلية الحجز.
- صفحة 404 مخصصة، ومظهران فاتح وداكن، وقائمة متجاوبة مع الجوال.

## المحتوى والهوية

- شعار وصور الهوية الأصلية التي أرسلها المستخدم محفوظة دون تغيير في `public/brand/`.
- يعرض مكون `src/components/brand.tsx` نسخة محسّنة للويب من الشعار الأصلي، ويستخدم CSS لإخفاء الفراغ الخارجي في العرض فقط. لم يُعد رسم الشعار.
- أوصاف الدورات والمسارات في `src/lib/courses.ts`، والرقم وروابط واتساب في `src/lib/contact.ts`.
- لا توجد أسعار أو مواعيد أو مدربون أو اعتمادات أو شهادات مختلقة. لا يُعرض منهج الدورة أو دروسها؛ يرسلها المركز عبر واتساب.
- صور الدورات الحالية مأخوذة من مواقع التدريب المذكورة في `research/asset-sources.md` بناءً على طلب المستخدم. هي صور توضيحية للمجالات وليست توثيقًا لقاعات المركز أو طلابه. أصول الصور وروابطها في `research/saudi-course-images/`.
- استُخدم الموقع المرجعي للمقارنة، ثم لاختيار صور بعض الدورات في التحديث اللاحق. بقيت هوية الموقع وبيانات الاتصال خاصة بمركز تفاصيل.

## الحجز

رقم الاتصال: 0558815053. رقم واتساب: 0544552366، والرابط: https://wa.me/966544552366

تمر أزرار واتساب وطلبات الحجز بنموذج بيانات المتقدم أولًا. ينقل زر الدورة اختيارها إلى النموذج تلقائيًا. الاسم الكامل ورقم الجوال والدورة حقول مطلوبة؛ المدينة والملاحظات اختياريتان، ويتاح طلب المساعدة في اختيار الدورة.

يتحقق النموذج من رقم الجوال السعودي ويدعم الأرقام العربية والإنجليزية وصيغتي `05` و`+966`. ثم يحوّل البيانات إلى رسالة مرتبة يمكن مراجعتها والعودة لتعديلها دون فقد المدخلات. لا يحدث إرسال تلقائي ولا تُحفظ بيانات الطلب في التخزين المحلي أو في قاعدة بيانات. فتح واتساب يهيئ الرسالة في الخدمة الخارجية، ويرسلها الزائر بنفسه. يؤكد المركز الحجز عبر المحادثة.

## إضافة الباك إند لاحقًا

1. أزل `output: 'export'` من `next.config.ts` إذا احتجت وظائف خادم داخل Next.js.
2. استبدل مصدر بيانات الدورات الثابت في `src/lib/courses.ts` بمصدر من قاعدة البيانات أو CMS، مع الحفاظ على الحقول المستخدمة في الواجهة.
3. أضف صلاحيات إدارة للدورات ونظام الحجز فقط عند تجهيز الباك إند؛ لا توجد واجهة تسجيل دخول وهمية حاليًا.
4. إذا بدأت حفظ طلبات الحجز، حدّث آلية الإرسال والإشعارات وصفحة الخصوصية بما يطابق السلوك الجديد.
5. استخدم `next start` بدل خادم الملفات الثابتة عند التحول إلى تشغيل ديناميكي.

## النشر

`npm run build` ينشئ مجلد `out/` الجاهز للاستضافة الثابتة مع دعم مسارات المجلدات وملف `404.html`.

يُنشر فرع `main` تلقائيًا على GitHub Pages من خلال `.github/workflows/deploy.yml` بعد نجاح البناء وفحص الأنواع وESLint. تُضبط قيمة `NEXT_PUBLIC_SITE_URL` على رابط الموقع الكامل و`NEXT_PUBLIC_BASE_PATH` على `/tafaseel-training-center` أثناء البناء، حتى تعمل روابط الصفحات والصور والخطوط تحت مسار المشروع. عند غياب الرابط يمنع الموقع فهرسة المعاينة المحلية.

لمعاينة بناء GitHub Pages محليًا:

```sh
NEXT_PUBLIC_SITE_URL=https://az212z.github.io/tafaseel-training-center NEXT_PUBLIC_BASE_PATH=/tafaseel-training-center npm run build
NEXT_PUBLIC_BASE_PATH=/tafaseel-training-center npm start
```

ثم افتح `http://localhost:3014/tafaseel-training-center/`. عند الربط بنطاق مستقل أفرغ `NEXT_PUBLIC_BASE_PATH`، وحدّث `NEXT_PUBLIC_SITE_URL` ثم أعد النشر.

```sh

```


للتحقق من النشر العام بعد بناء النسخة نفسها محليًا:

```sh
python3 scripts/verify-static.py https://az212z.github.io/tafaseel-training-center
```

تقرير المقارنة في `research/brief-and-comparison.md` ومصادر الصور في `research/asset-sources.md`. نتائج الفحص والأرشيفات والأصول الخام في `output/` ومجلدات البحث المحلية مستثناة من Git؛ صور الإنتاج موجودة ضمن `public/`.

# النسخة المقارنة V2

النسخة الجديدة منشورة في `/v2/`، مع صفحات الدورات والمسارات والحجز والتعريف والسياسات تحت المسار نفسه. الرابط العام: https://az212z.github.io/tafaseel-training-center/v2/

تجمع واجهة افتتاحية بصور حقيقية من المركز وأغلفة موحدة للدورات الـ13 بأسماء عربية فعلية والشعار الأصلي. العروض الجديدة محددة داخل `src/app/v2/v2.css`؛ وتُعاد الاستفادة من بيانات الدورات ونموذج الحجز في النسختين. توليد روابط النسخة في `src/components/version-link.tsx` يحفظ مسار V2 ومعامل اختيار الدورة أثناء التنقل.

## صور المركز في V2

معرض `/v2/gallery/` يعرض ثماني صور مختارة من المجموعتين اللتين أرسلهما صاحب الموقع في 16 سبتمبر 2026، مع تصفية حسب المساحة وعرض الصورة كاملة والتنقل بلوحة المفاتيح. تظهر صور مختارة أيضًا في الرئيسية وصفحة عن المركز.

عولجت الصور بأداة `image_gen` المدمجة لتحسين الإضاءة وتوازن الألوان بدرجة هادئة. ملفات الويب بصيغة WebP وصور المعاينة المصغرة في `public/images/facility/`، وبيانات المعرض والنصوص البديلة في `src/lib/facility-photos.ts`. الصور المصغرة تُحمّل عند الاقتراب منها، وتُحمّل الصورة الكاملة عند فتحها. تفاصيل المصدر والمعالجة في `docs/facility-images.md`.

V2 صفحة مقارنة مستقلة مستبعدة من فهرسة البحث ومن خريطة الموقع، بينما تبقى النسخة الأساسية قابلة للفهرسة. لا توجد أسعار أو مواعيد أو محتويات تدريبية مفترضة، ولا إرسال تلقائي لرسائل واتساب.
